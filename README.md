# iROOTECH 无人叉车 · 问题反馈 + 需求池（演示版）

- **手机端（一线人员提问题）**：https://kyyoki-stack.github.io/irootech-feedback-demo/
  选身份 → 选现在情况（5 档）→ 打字 / 录音 / 拍照 / 拍视频 → 提交 → 在"我的问题"里看处理进度。
- **产品经理端（需求池）**：https://kyyoki-stack.github.io/irootech-feedback-demo/admin/
  AI 自动分类、按优先级排序（带理由）、识别相似问题一键合并、六种处理结果回给提交人、看板、统计。

这是演示版：没有服务器，数据只保存在当前浏览器里；预置了一池示例问题。在同一个浏览器里先用手机端提问题，再打开产品经理端，就能看到它进入需求池。
